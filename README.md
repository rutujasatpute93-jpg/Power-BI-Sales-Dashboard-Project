# Power BI Sales Performance Dashboard

## Project Description-

This project focuses on analyzing sales data and developing an interactive Power BI dashboard to monitor business performance. The dashboard provides insights into total sales, profit, quantity sold, profit margins, product category performance, sales trends, and customer payment preferences.

The project uses Excel datasets containing sales transactions and product master information. Data cleaning and transformation are performed using Power Query, while DAX is used to create calculated columns and measures for business analysis.

## Objectives
- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Track monthly and yearly sales trends.
- Analyze sales by payment mode and sales type.
- Evaluate discount impact on profitability.
- Build interactive reports using slicers and filters.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

## Key Features
- Interactive KPI cards.
- Monthly sales trend analysis.
- Category-wise sales and profit analysis.
- Top 10 product performance.
- Payment mode and sales type analysis.
- Year-wise and quarterly sales analysis.
- Interactive slicers for dynamic filtering.
